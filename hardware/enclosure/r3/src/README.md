# CyberMachine R3 参数候选

本目录生成一体机箱重构候选。模型单位为毫米。R1 正式打印资料和 R2 教学模型不随此候选改变。

水平6mm横带的本轮数字交付已冻结为R3 Final 2026-11-24。正式STEP位于[../cad/](../cad/)，五盘原生3MF与打印姿态STL位于[../print/](../print/)。本目录继续向`outputs/`生成候选，不覆盖已冻结文件。实物试装待验，使用前阅读[独立指南](../../../../docs/design/r3/final-guide.md)。

## 结构与坐标

- 外壳总包络为 154×144×194 mm，世界 X=−5..149、Y=28..172 mm。中心保持(72,100)。底壳高度174 mm，上盖外缘仍从Z174.3开始。横向各加宽5 mm，给竖锁座和内总成直提留出空间。
- 底壳、上盖、主架、后扇框与五个同款盘托组成9个主要打印件。脚垫、风扇、电子件与五金另计。
- 外壁 2.8 mm，外角半径 8 mm。上盖内止口单侧间隙 0.35 mm，向下伸出 5 mm，实际咬合 4.7 mm。
- 壳内四个45°承台在Z169.3接触止口底面。四处盖压套在Z174接触D座。承台确定0.30 mm外观缝；四颗竖向M3锁盖。打印收缩、翘曲和合盖手感仍需试片验证。
- 原厂 TACO STEP 绕 Y 轴转 180°，再平移 (72.1,120,135) mm。保留全部730个实体，以及真实USB-C开放壳`native-usbc-shell`。USB-C壳不是闭合实体，不强制实体化；其余非实体参考节点不发布。
- PCB 背面 Z133.4、正面 Z135。四孔承托顶段 Ø5 mm，较粗柱段在 Z129 停止。承力肋最高 Z116，不使用横跨板底的托板。
- SATA X=29/50.5/72/93.5/115。用户确认五盘均为7 mm，候选只保留此厚度。硬盘统一负 X 底面基准，两颗前侧螺丝固定，五个盘托使用同款几何。硬盘孔位和 SATA 插入深度沿用旧设计基准，仍需实际型号试装。

内骨架保留两片开窗桁架。纵向腹板厚2.4→3.6 mm，第一片向负X加厚至X17.7..21.3，给首盘前螺丝保留指尖空间；第二片为X103.8..107.4。周框及板孔下直承力带最窄8 mm，斜撑宽6→8 mm。底框从Z8..12加高到Z8..14；跨X底梁为X7..137/Y70..78/Z8..14，顶面距盘托底面5.85 mm。横梁把两片桁架连为同一实体。

后梁下表面仍为Z22.25，梁高及盘托铜套盲孔保持原值；六道梁下竖筋厚2.4→3.6 mm。后扇立柱厚6 mm，四角各保留18 mm腿长、4 mm厚三角肋，位于Y134..138。后侧两根主板立柱保留实体。

主架保留直立打印。两片桁架的窗顶改成45°尖拱，尖端Z108；两个窗的坡起点分别为Z101.4和80.1。原顶部8 mm承力带和斜撑保留。后扇框沿Y138分件，框厚4 mm；后面Y142朝床平放，前伸定位键朝上。主架不再打印后框的高处横跨桥。上方螺丝座加45°坡，后梁盘托止挡仍保留低处局部支撑，避免侵入盘托抽取路径。

后扇框有两个3×1.5×5 mm定位键，中心为X12.75/132.75、Z68。主架槽为3.6×1.8×5.6 mm，侧边、端面及槽底净空均为0.3 mm；立柱槽边剩余1.2 mm。键负责对齐，四颗原有风扇螺丝夹紧接合面，不新增螺丝或铜套。四颗后扇螺丝统一改为M3×35。主架套孔Ø4.1从Y131.6至138，后框通孔Ø3.4从Y138至142；头下Y167、尖端Y132，孔底余量0.4 mm。名义5.4 mm铜套从Y138安装；实际铜套规格仍须确认。

四处主板根筋从Z103.5/R1.2以45°展开至Z107.8/R5.5，再收至Z116/R3.5。前两处裁至X23.95/109.95，后两处裁至Y≥114.4，避开盘托顶带与后肩。根筋位于板底元件下方；Ø5承托顶段和Z133.4定位面不变。以上是材料截面设计，刚度、疲劳和振动仍需实测。

盘托以负X侧框、底梁和四块端部短肩承托硬盘。侧框接触区前边6 mm、后边6.10 mm、下边12.75 mm、上边10 mm。底部两条纵梁宽2.6 mm，中间横带宽6 mm。前螺丝短肩为9.5×9 mm；Ø3.4通孔至外边至少2.8 mm。螺丝与垫圈外径5.5 mm时，短肩外缘余量至少1.75 mm。偏置后耳、铜套位置和插入终点不变。

2026-11-24历史减料基线：内骨架体积109383.40→82897.49 mm³，随后加固为111642.92 mm³，打印分框后为118869.80 mm³。本轮主架109040.62 mm³、后扇框10645.73 mm³，合计119686.35 mm³，较打印分框轮增加0.69%。本轮侧梁改位去除3602.85、新增4419.41 mm³。比较合并主架与后框，并用实体差集核对体积恒等式。单盘托保持8291.73 mm³，负X基准面接触面积保持2437.72 mm²。体积不能证明刚度、抗振或寿命。

## 四角竖锁与底脚根

四轴为XY=(3,48)/(141,48)/(3,152)/(141,152)。M3圆头×25从顶部拧入壳座，头径≤5.7、头高≤1.7 mm，不加垫圈。沉孔Ø6.3从Z191.8至194；杆孔Ø3.4。头顶Z193.5，低于外顶面0.5 mm；尖端Z166.8。壳导孔Ø4.1从Z166.4至174，盲底余量0.4 mm。名义5.4 mm铜套从174装至168.6，实际铜套规格待确认。

D座贴侧壁，内区左X−2.2..8.2、右135.8..146.2，Y为轴心±6，Z164..174。内侧两角R2，接墙边平直。导孔至内侧自由边3.15 mm；外侧到外壳表面4.85 mm，并连续接入侧壁。座底45°坡从墙内X−2.3/146.3、Z153.5逐层长至内缘Z164，不打印孤柱。孔底下有2.4 mm材料。盖压套外Ø12、底Z174；Ø16根在Z187.2..189.2以45°展开，完整根部与外轮廓X−5/149相切。原厂板X包围盒至左座内缘保守余量0.98418 mm；独立座区投影检查的最小板净空为1.0 mm。

连续止口在每个D座内侧用2.4 mm厚U形带绕行，与座边留0.35 mm。左内伸至X10.95，右至133.05；U带Y范围为轴心±8.75。四个止口承台移到Y70..78及122..130，顶Z169.3。四压套各接触96.65675 mm²，合计386.62701；另四承台76.8，总接触463.42701 mm²。接触面积不等于夹紧强度。

固定壳座必须避开内总成的整段上提路径。左、右底侧梁改至X13.5..19.5和124.5..130.5，Z8..14；原四脚孔和接触Z8不变。前角板左XY=(10,36)/(24,36)/(18,50)，右镜像，避开前D座；壳底Ø9脚座用3.2 mm竖筋连接侧壁，左筋X−2.3..6.2、右筋137.8..146.3。跨X底梁和盘托下5.85 mm余量不变。实际板实体、主架、盘托和后扇均与新D座的全高XY柱隔离，另保留整体提升采样。

## I/O 前端校准

`io_geometry.py` 定义七组独立开孔。前缘位置分别为双RJ45的Y33.05、双USB-A的Y33、HDMI的Y33.4、SW2按钮的Y33.44007，以及竖向USB-C和DC的Y34.35。孔壁外面为Y28，内面为Y30.8；外侧1 mm使用45°导入口，后方保留1.8 mm直孔段。

孔形来自原厂前端面，未沿用含引脚的包围盒。HDMI使用轮廓孔，按钮使用Ø4.2工具孔，USB-C使用竖向长圆孔，DC使用Ø8圆孔。双USB-A共用贴合其前端外壳的窗口。SW2与USB-C分别开孔；USB-C开放壳保留862个原厂面，不转换成无效实体。接口内缩仍为约5–6.35 mm，实际插头包胶、卡扣和按钮行程需试片核对。

`check_io.py` 独立读取原厂前端面，连续扫出接口嘴部与按钮工具量规，检查整个壳壁的孔道。另以表面距离检查USB-C开放壳至全部打印件；故意封住USB-C验证漏孔检测。量规不包含具体电缆胶套。

## 一体顶扇盖

顶扇使用92×92×14 mm最大外形包络，中心为上盖几何中心(72,100)，平面框体X26..118、Y54..146。距154×144 mm外轮廓的左右边各31 mm、前后边各26 mm。框体Z175.2..189.2。四孔XY为X30.75/113.25与Y58.75/141.25。14 mm包含风扇自带软垫；不另外预留隔振垫厚度。额外垫片会改变散热器净空和螺纹余量。实际型号、82.5 mm孔距和Ø4.3安装孔需选型确认。

顶板内面Z191.2，四个Ø9硬座高2 mm。PETG硬座提供定位，不构成橡胶隔振。风扇盒底至Z170散热器包络保留5.2 mm；四角螺丝尖端到Z171.8，其净空另外检查。M3×20头下承压面在Z191.8；平垫Z174.7..175.2，薄螺母Z172.9..174.7。夹紧栈17.1 mm，螺母厚1.8 mm，名义剩余1.1 mm。圆柱沉孔不能配锥形沉头螺钉。头高2 mm的普通低头螺丝超过本设计上限。轻拧至贴合，PETG座不能套用钢件紧固扭矩。

一体格栅改为七道同心断环，中心半径4.4/10.4/16.4/22.4/28.4/34.4/40.4 mm。环槽宽3.2 mm，径向节距6 mm，径向筋2.8 mm；四向4 mm直筋把环形筋连到盖体。外径84 mm，四角螺丝远离开孔。最长外环自由弧长约59.46 mm；同心图案不代表格栅刚度增强。开放面积写入`metadata.topFan`；它不证明实际风量或风扇安全认证。

后侧X65..79/Y148..162/Z169.3..189.2为空引线区。它距扇框后缘2 mm；空区不证明具体角落出线、弯曲半径、插头、供电能力或抬盖余线。

## 通风纹样

前后主通风区采用十五列管风琴式圆端槽。槽中心X16..128、节距8 mm、槽宽4.4 mm、端圆半径2.2 mm。开口总包络为X13.8..130.2/Z14..126。外侧端点保持对称缓拱；靠中间的端点统一为Z67与73。中线Z70、等宽6 mm的水平横带连接各列细筋。相邻列最窄筋宽3.6 mm。前后用同一参数轮廓，后上舱保留十五个圆端短槽。

孔槽面积来自挤出切具体积与独立STEP截片两条路径；`metadata.ventilation`保存每孔X/底/顶、横带Z范围、穿壁厚度及区域面积。2026-11-24水平横带候选每面主区6404.40 mm²、后上舱1412.57 mm²、顶格栅2791.27 mm²；后扇Ø110扫掠圆内4759.29 mm²。弧形4 mm横带基线分别为6536.40与4878.04 mm²；本轮减少约2.02%与2.43%。更早矩形主槽为5880 mm²、扫掠内4723.77 mm²。面积只比较名义开口，不能代替风阻或温升测试。

## 构建与输出

使用 text-to-cad 提供的 `cad` 命令与其 build123d 运行环境，不依赖个人 Python 绝对路径。模型从自身文件位置定位仓库。

```sh
cad run hardware/enclosure/r3/src/design.py
cad run hardware/enclosure/r3/src/export_candidates.py
cad run hardware/enclosure/r3/src/validate.py
cad run hardware/enclosure/r3/src/check_board.py
cad run hardware/enclosure/r3/src/check_mating.py
cad run hardware/enclosure/r3/src/check_fastening.py
cad run hardware/enclosure/r3/src/check_service.py
cad run hardware/enclosure/r3/src/check_frame.py
cad run hardware/enclosure/r3/src/check_io.py
cad run hardware/enclosure/r3/src/check_top_fan.py
cad run hardware/enclosure/r3/src/check_vents.py
python3 hardware/enclosure/r3/src/check_mesh.py
python3 hardware/enclosure/r3/src/check_dfm.py
python3 hardware/enclosure/r3/src/slice_candidates.py
python3 hardware/enclosure/r3/src/check_print.py
```

`design.py`声明模型。`export_candidates.py`导出到忽略目录`outputs/redesign-r3/`，包含整机STEP、五种装配分件STEP/STL、四份变换后的打印朝向、购买件`top-fan.step`、`preview.glb`和`metadata.json`。顶扇STEP不是打印件。`parts`只列装配件；`printParts`列底壳及四种打印朝向和各自数量，合计9件。`printTransforms`记录装配坐标至实际导出朝向的旋转和平移；底壳沿用装配XY且底面Z0。`profiles`记录PETG FDM、256 mm构建体积、0.4 mm喷嘴和0.2 mm层高。原板、设计、GLB及各STEP哈希绑定同轮输入。

GLB使用米、Y向上，映射为CAD `[x,y,z]` → glTF `[x,z,-y]/1000`。20个顶层语义节点为`shell`、`lid`、`spine`、`rear-fan-frame`、`carrier-1..5`、`drive-1..5`、`taco`、`rear-fan`、`top-fan`、`lid-fasteners`、`cm5`、`cooler`。`lid-fasteners.step`仅为4颗金属螺丝，不是打印件。页面中它随盖展示；真实拆卸先旋出。`lidClosure`记录D座、U止口、压套和紧固栈；`baseMounts`记录改位底梁和脚根筋。

## 检查与限制

`validate.py`检查打印件、主板730实体、五盘7 mm和购买件。主板装配干涉、顶扇干涉、壳座全高投影和提升后干涉均逐个闭合原厂实体求交，包含PCB实体0。原厂混合整树和纯730闭合实体Compound布尔均漏掉已知碰撞；两者不再用于主板判定。旧144 mm候选的左座投影作为失败对照，必须检测到PCB及原厂元件交叠。该投影逐件交集之和为157.04615 mm³，其中PCB为44.16 mm³。报告保留两类Compound的0值以便诊断。

提升保留10 mm离散位姿及保守板盒结果；保守盒与壳体产生假阳性时，另测730实体，不覆盖原失败值。交叠量为逐实体交集之和，不是合并体积。新增四座使用贯穿实际内总成高度的XY柱，零交集证明新增座对任意Z直提隔离。原壳面仍使用离散位姿。线缆、焊脚实测和插接行程不在证明范围。

`check_board.py` 独立检查四个孔周承托、M2.5 螺丝杆与螺丝头，并故意加粗杆件确认检查能够报错。结果和本轮输入哈希保存在 [R3 验证目录](../../../../validation/r3/)。

`check_mating.py`分别测Z169.3四承台76.8 mm²、Z174四压套386.62701 mm²，合计463.42701 mm²。每个压套必须接触，不能用总面积掩盖悬空。另测实体零交叠、外观缝0.30 mm及单侧间隙0.35 mm。名义值不代替配合试片。

`check_fastening.py`独立读取最终STEP，测四点竖锁、完整沉孔环壁、压套落座、铜套/螺杆/盲底和工具净空、底脚连筋及失败对照，不推断强度。其输入绑定最终STEP。

`check_top_fan.py`独立读取顶扇、上盖及盖锁STEP，测格栅、四角顶扇紧固件、5.2 mm风扇净空，以及四盖螺丝旋出后提盖采样。盖压套与顶扇硬座分别检查。格栅和垫圈面积不证明风量或强度。

`check_vents.py`独立读取上盖和底壳STEP，核对28个断环开口、径向槽宽、四向连筋、主区30个圆端槽及后上舱15个短槽。逐列测Z67/73端点与6 mm横带，再用连续实体条核对材料。`--straight-baseline <目录或shell.step>`读取旧弧形横带，确认水平检查能拒绝该失败对照。截片检查面积、对称和贯通，不从渲染图估算开孔率。

`check_service.py`从当前内骨架的圆柱面测铜套盲孔深度，并用孔内、孔底和螺杆实体复核孔底。逐盘前螺丝使用Ø6直杆和Ø14短圆柱指尖包络；后风扇使用Ø6直杆。顶扇在拆下盖上检查Ø6上方直杆与Ø9下方套筒包络。指尖圆柱不代表整只手，结果不证明握持和实际装配手感。

`check_frame.py`独立读取最终STEP，核对五盘7 mm、加固截面、尖拱、键槽五面净空和35 mm螺丝。故意加宽定位键确认碰撞检测会报错。材料比较使用打印优化前归档；给出`--baseline`目录时测实体材料加减，并核对体积恒等式。测量不把截面增加等同于力学验证。

`check_dfm.py`核对设计和I/O哈希，再检查`shell`、`lid-print`、`spine-print`、`carrier-print`、`rear-fan-frame-print`五种实际朝向。原始日志写入`work/redesign-r3/dfm/`，汇总记录警告及对应STEP哈希。命令依赖同轮CAD模型服务。

PETG FDM通用检查使用256×256×256 mm、0.4 mm喷嘴和0.2 mm层高。底壳及主架直立，上盖顶面朝床，盘托负X大面朝床，后框Y142朝床且键朝上。盘托打印高度由94.15降至14.3 mm，后框打印高度5.5 mm。I/O上沿和主架后梁仍有局部支撑或桥接；不能声称整套无支撑打印。`slice_candidates.py`对这些实际朝向执行独立生产配置切片，结果与输入哈希保存在验证报告。

`check_mesh.py`读取九份导出STL，以0.00001 mm坐标合并检查每条边的使用次数与方向、连通体和有向体积。九份包含装配坐标副本，不等于九种零件。结果记录STL哈希。闭合网格不等于消除所有自交。

切片结果与数字几何分别记录。实物打印、装配、温升、振动和噪声仍未验证。候选STEP/STL不属于正式R3打印包。

切片完成后运行`check_print.py`。脚本核对机型、工艺和材料三份预设的SHA256，逐字节比较3MF内外G-code，并独立重算五盘路径。路径包络包含标称半线宽和I/J圆弧极值。脚本检查256×256×250 mm床面、左前18×28 mm禁区、多件盘路径间距及后框零支撑。结果写入`validation/r3/printing-audit.json`。检查排除机器准备段，采用保守AABB；它不证明实物支撑可拆、打印质量或配合。
