# CyberMachine R3 · 一体机箱候选

打开 [三维设计页面](index.html)，可离线旋转、拆解、逐口查看 I/O、查看主板正反面，并检查箱外预装总成及独立骨架。页面内嵌 CAD 网格与接口截面，不请求远程字体、脚本或模型。

R3 Final 2026-11-24 已冻结本轮数字交付，提供[原生五盘3MF](../../../hardware/enclosure/r3/print/CyberMachine-r3-final-20261124-p1s-petg.3mf)、[总成STEP](../../../hardware/enclosure/r3/cad/CyberMachine-r3-final-20261124-enclosure.step)和[独立装配指南](final-guide.md)。实物试装尚未完成；页面的候选标识保留这一验证边界。R1仍按[R1说明](../../assembly/r1.md)使用。交互拆解位移不是安装行程。

## 改了什么

| 结构 | R3 候选 |
| --- | --- |
| 外壳 | 一体底壳与整体上盖，连续 R8 圆角 |
| 外形 | 154 × 144 × 194 mm，脚垫另计 |
| 接缝 | 名义可见缝 0.30 mm，止口单侧间隙 0.35 mm |
| 主板支撑 | 四孔 Ø5 mm 小承托台；取消横跨板底的托板 |
| 内骨架 | 一体主骨架以底脚连筋接入四个底部锁点，后风扇框独立平放打印 |
| 硬盘 | 固定五块 7 mm 硬盘，五个同款托架保留 SATA 原始基准 |
| 装配 | 箱外预装内部总成，再整组入箱 |
| 总成锁紧 | 壳底四颗 M3 向上固定骨架，头部藏在底部沉孔 |
| 上盖锁紧 | 四处内置厚座，四颗 M3×25 竖向压紧；头部低于顶面 |
| 主要打印件 | 9 件：底壳、上盖、主骨架、后风扇框、五托架；脚垫及五金另计 |
| 风扇 | 顶置 92 × 14 mm 进风，后置 120 × 25 mm 排风；风量与温升待测 |
| 通风图案 | 顶部居中同心断环；前后15列管风琴式圆端分段槽 |

顶扇的 14 mm 是含自带软垫的最大总厚度。原R1的92×25 mm顶扇不适配当前R3高度。风扇固定在上盖一体座，格栅由上盖直接成形；顶扇固定不增加主体打印件或铜套。顶扇框底 Z175.2 mm 至散热器 Z170 mm 设计包络留 5.2 mm，不把这个距离当作完整线束或实物散热器的配合结论。断电后完整旋出四颗盖螺丝，再小幅提盖并断开顶扇接头；具体风扇、接头与线束尚待选型验证。

外宽采用 154 mm，为侧壁连体厚座与真实主板的上提轮廓留空间。外壳与上盖的 X 范围为 -5..149 mm；主板、盘位和内框保留原始坐标。上盖由四颗竖向 M3×25 锁紧，四个轴位关于 X72 与 Y100 对称；准确坐标读取同批 CAD 元数据。四处壳座与盖座在 Z174 mm 接触，承接锁紧压力。螺丝采用头径不大于 5.7 mm、头高不大于 1.7 mm 的圆头规格，头顶 Z193.5 mm，低于 Z194 mm 外顶面。四颗螺丝必须完整旋出后才能提盖。页面用独立螺丝实体表达锁点，拆解展示时与上盖共同移动；这个展示不代表螺丝被上盖扣留。螺丝、铜套与厚座的实际配合仍需试装。

顶扇与同心纹中心为上盖几何中心XY=(72,100) mm。92 mm 顶扇的左右边距为 31 mm，前后边距为 26 mm。七道同心断环的名义环宽为3.2 mm，保留2.8 mm径向筋和4 mm四向连筋。前后圆端槽按对称缓拱收边，以横向连接带分段；后上舱延续圆端短槽。开孔面积与刚度、风量分别验证，图案不代表散热性能结论。

原厂主板参考来自 [TACO V1.61 STEP](../../../references/radxa-taco/radxa_taco_3d_stp_v1.61.stp)。主板正反面保留真实元件几何。CM5、散热器与硬盘是设计包络；它们的配套尺寸和插接深度需实测。颜色用于识别结构，不代表原板材料或表面工艺。

本次独立数字检查给出：Ø5 mm 承托柱至原厂非 PCB 元件的最小距离约 1.87 mm，安装孔的有意座接接触除外。这个数值仅覆盖原厂主板；它不证明 CM5、散热器、实际焊脚、螺丝规格与工具空间已完成实物验证。原厂背面最大下凸 10.70 mm、正面最大上凸 15.50 mm 是器件高度，不是空余净空。

主骨架保留 3.6 mm 纵肋、8 mm 斜撑、6 mm 底框、底部横梁及主板立柱根筋。底脚连筋把四个锁点接入底框。开窗顶部改为 45° 尖顶，减少水平悬空。后风扇框从主骨架分出，以两个浅定位键就位，与风扇共用四颗 M3×35。热熔铜套共 21 个，其中 M3 为 17 个，M2.5 为 4 个。分件保留箱外预装方式；CAD 实体体积不代表刚性或承载结论。

打印朝向按零件分别定义：底壳开口向上；上盖外顶面贴床；主骨架直立；盘托以负 X 侧大平面贴床；后风扇框以 Y142 后面贴床，定位键朝上。打印版与装配版使用独立变换，页面展示装配坐标。[打印与装配说明](printing.md)列出五盘配置、试装顺序和五金；切片结果见[打印分析](../../../validation/r3/README.md)。去支撑操作、表面质量与实物配合仍需打印验证。

## 页面操作

- 「外观」显示完整机箱；「拆解」显示各结构层，可拖动滑块任意前进或回退。
- 「外观」中的「顶部」只切换取景，查看上盖格栅、顶扇和四个盖螺丝；再次点击「整体」恢复外观镜头。拆解示意将顶扇及四颗盖螺丝与上盖共同移动；真实提盖前须完整旋出盖螺丝，展示位移不代表装配行程。
- 「外观」中的「背面」查看后部格栅；再次点击「正面」恢复外观镜头。顶部、背面与I/O近景互斥，切换取景不移动模型。
- 「外观」中的「I/O 细节」进入逐口近景。选择接口按钮或实际孔口，同时高亮 CAD 开口与原厂接口实体。项目与数量读取 CAD 元数据，区分按钮和 USB-C。外孔、内孔尺寸读取本次 CAD 截面；前缘包络退距只描述接口实体包络，不代表插头插入深度或实物配合。
- 「主板净空」隐藏壳体和硬盘，保留真实主板与四孔支撑；「看板背面」切换观察方向。金色圈标出四个安装孔。
- 「箱外预装」显示可取出的内部总成，包含后置风扇，不含上盖和顶扇。取景按全部可见部件包络适配。点盘位按钮或可见硬盘可高亮对应盘位；在外观视图选择盘位会转入内部总成视图。
- 「箱外预装」中的「仅看骨架」显示主骨架和后风扇框，隐藏主板、风扇、硬盘和托架，并清除盘位高亮。取景包含两个结构件。选择盘位会恢复总成。
- 页面固定为五块 7 mm 硬盘，直接展示同批 CAD 的真实尺寸。每盘保留负 X 侧与 SATA 的原始基准。
- 拖动旋转，滚轮缩放，复位按钮恢复当前预设。三维区域获得焦点后，数字 1–4 切换视图，左右键选择盘位；I/O 近景内改为选择接口。Home 复位，Escape 取消高亮。
- 支持深浅主题和 390px 布局。减少动态效果时直接切换镜头；场景离屏或页面隐藏时停止渲染，返回时恢复。

## 重建

先生成 [R3 CAD 候选](../../../hardware/enclosure/r3/src/README.md)。构建读取 `outputs/redesign-r3/preview.glb`，也兼容 `assembly.glb`，并读取同目录的 `metadata.json`；从脚本自身位置解析仓库，不依赖当前工作目录。元数据带模型 SHA256 时，构建拒绝不匹配的导出批次。没有接口元数据时，页面禁用 I/O 细节。依赖沿用 R2 锁定版本。

```sh
cd docs/design/r3/src
npm ci
npm run build
npm run test:browser
```

候选 GLB 与其他中间输出留在仓库忽略目录。页面构建会将压缩网格及 MIT 许可文本嵌入 `index.html`，因此离线分发无需携带忽略目录。也可指定其他候选：

```sh
node docs/design/r3/src/build.mjs --model=/absolute/path/preview.glb
```

浏览器检查默认使用本机 Google Chrome（存在时）或 Playwright Chromium。可设置 `CHROME_PATH` 指定浏览器，不自动下载。本轮 15 组检查与 21 张桌面、手机、拆解、主板两面截图写入 `work/redesign-r3/ui-review/`。检查记录包含相机位置，并断言真实画布拖动改变相机位置。全页截图会触发响应式复位，因此拖动结果在截图前单独读取并记录。

验收通过后，将`work/redesign-r3/ui-review/report.json`复制到`validation/r3/browser.json`，再更新根完整性清单。候选检查与正式证据分开保存。

运行依赖使用 three.js；构建使用 Vite，浏览器检查使用 Playwright。版本沿用 R2 的锁文件。模型出处与 MIT 许可文本见 [credits.md](credits.md)；完整依赖记录见 [R2 许可证汇总](../../assembly/r2/assets/third-party-licenses.txt)。

## 验证边界

页面验证覆盖离线资源、九件计数、四视图、五盘真实 7 mm 尺寸及 SATA 基准、四颗盖螺丝与顶扇包络及共同位移、后扇框与后扇共同位移、双件骨架包络、顶扇平面居中、前后顶部取景、全部接口轮廓与原厂实体绑定、盘位、键盘、主题、390px、减少动态效果、离屏暂停及 WebGL 降级。外观测量包含上盖最高点。报告同时记录 HTML、GLB 和元数据 SHA256。CAD 的实体有效性、器件距离、相交、打印朝向与切片由独立流程检查。

最终外壳接缝需要用实际 PETG 与打印机校准。实物焊脚、CM5 散热器高度、螺丝头及工具、硬盘插接行程、温升、振动和噪声没有实测结论。完整设计依据见 [topic.md](topic.md)。
