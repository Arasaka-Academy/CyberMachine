# 本教程的检查约定

- 2026-11-06：装配动作从操作面规划，不能把展示展开位移直接当成行程。检查：对纯位姿函数导出全部采样，再用原厂 STEP 和参数实体检查接触。
- 2026-11-06：工作台上的待装零件也会互相碰撞。检查：起始与等待状态纳入审计，不只检查移动末端。
- 2026-11-06：检修盖会受到脚垫边角阻挡。检查：盖先装、脚垫后装，并检查全部中间位置。
- 2026-11-06：插接轴线正确，补绘插槽的侧缘仍可能挡住倾斜卡板。检查：角度与位移一起采样，单独记录有意插接接触。
- 2026-11-06：近景可以裁掉非当前组件，但当前连接点必须留在画面内。检查：桌面、390px 与影片各自实拍，逐帧测量当前对象。
- 2026-11-06：盘位间距小于安装标记的宽度。检查：同一步只标出对应盘位；需要辨别的 E-Key / M-Key 两个标记分别检查可点击性。
- 2026-11-06：天线管线不能穿入散热器或引出到无孔的外壳外。检查：使用内置 FPC 示意，按实际曲线采样线径、风扇与主板实体距离；射频性能仍单独实测。
- 2026-11-06：自动演示切换盘位时，要把当前盘位写回选择状态，避免暂停后高亮和透明度跳回旧盘位。检查：在第三盘移动中暂停，比较暂停前后全部零件的位姿及强调状态。
