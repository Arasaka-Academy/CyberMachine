# 2026-11-06 · 页面与影片复查

离线浏览器已验证五章、任意跳步、上一步/下一步、暂停与重播、三种厚度、三主题、盘位、旋转、实体选择与装配练习。练习检查错误 M-Key、缺垫片、缺固定件和过早封盖；手机使用触摸事件安装，检查 390px 布局。

影片使用真实页面操作和虚拟时钟录制 900 帧，输出 30 秒、960 × 600、30 FPS 的无声 H.264 预览。第一版逐帧复查发现：镜头从固定件近景转到完整外观时，已出现的待装侧板挡住画面；错误提示停留造成重复帧。将侧板、风扇与盖板的出现推迟到外观镜头已退开之后，并在提示停留与完成状态进行真实小幅拖动旋转。

复核正式影片生成后的接触表、CM5 / E-Key / 四孔 / 固定件 / 封盖 / 错误提示关键帧，以及 `frame-guard` 测量与 `mpdecimate` 重复帧报告。结果汇总到 [影片记录](../../../../validation/r2/assembly-film.json)。桌面与移动截图保存到 [R2 图片目录](../../../images/r2/)。

收尾检查发现硬盘逐盘演示暂停时，高亮会切回上次手动选择的盘位。自动演示现在同步当前盘位；浏览器在第三盘移动中暂停，逐件比较播放与暂停状态的位姿、透明度和高亮，并重新生成操作预览。

剩余边界：E-Key 高度与通用天线、CM5 散热器含示意尺寸；影片为操作预览，不是实物安装录像。射频、打印公差与实物装配另行验证。
