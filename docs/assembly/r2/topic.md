# CyberMachine R2 · 3D 装配教学

工作目录：本目录；开发端口：5420。模式：lesson；视觉：Clean ops world，近距离观察真实零件。

## 已确认的目标

中文五章教学，加可自行操作的装配练习。使用 R2 四点固定结构、通用 M.2 E-Key 2230 无线模块、五块 2.5 英寸 SATA 硬盘。交付单文件离线 HTML、可维护源码、模型生成脚本和 30 秒低清操作预览。发布不属于本次工作。

## 事实与资料

- R2 外壳、导轨、托脚、四点固定与垫片来自现有 `../../anatomy/r2/src/model.mjs` 的三维解析几何。R2 尚无对应的制造 STEP / 打印件。
- TACO 采用仓库的 V1.61 原厂 STEP：绕 Y 轴 180°，再平移 (72.1, 120, 135) mm。保留 PCB、接口、安装孔与五个 SATA 的原始几何。
- 产品简介 Revision 1.2（2026-04-01）确认 V1.61 支持 CM5、M-Key 2280 NVMe 和 E-Key 2230 Wi-Fi / BT；原理图第 17 页标明 U33 为 E-Key。旧 CM4 网页不作为 V1.61 安装依据。
- CM5 外形 55 × 40 mm；两组 100-pin 板对板连接器分别与 TACO 原厂模型对位。模块与散热器细节为尺寸示意，紧固件按实际配套规格选用。
- SATA X 基准 29 / 50.5 / 72 / 93.5 / 115 mm；盘位 02 / 04 在混合模式中为 7 mm；7 mm 盘在正 X 侧加前后两条 2.5 mm 垫片。
- 四点固定每盘 M3×6 四颗、0.5 mm 垫圈；名义旋入量 2.25 mm，最终以硬盘允许深度为准。托脚承重，不顶压 SATA。
- 保留原厂资料字节。不下载外部模型和参考图片。两路内置 FPC 天线展示端子连接和避让走线，不新增机箱孔位，不承诺具体无线模块的驱动兼容性。

## 五章与镜头

1. 机箱准备：底框 → 导轨预紧 → 侧框 → 支架与隔离柱。前上方 3/4 镜头看清安装柱。
2. CM5 预装：台面支撑 TACO → 两组连接器对位 → 垂直压合 → 固定与散热器。上方近景看清两个连接点。
3. 无线网卡：E-Key 与 M-Key 区分 → 倾斜插入 → 压平固定 → 天线连接和走线。后上方近景看清缺口与尾部固定点。
4. TACO 入箱：预装总成沿开放的顶部进入 → 对齐四个不规则孔 → 固定。侧上方看清主板支架、SATA 朝下和 I/O 朝前。
5. 硬盘与收尾：7 mm 垫片 → 逐盘沿导轨向上插合 SATA → 整组对准 → 四点固定与托脚承托 → 风扇 / 面板 / 检修盖。低位近景观察选定盘，收尾回到完整外观。

每章一个进度控制，播放/暂停、重播、章节跳转及自由旋转。任意时刻的位姿由章节和进度直接求值，不依赖播放历史。装配运动独立于 Anatomy 的展示性展开位移。

## 风格卡

参考：`../../images/r2/exploded.png`、`../../images/r2/assembled.png`；保留项目现有白灰结构与青绿选中状态。

- 镜头：透视 30°，常用 3/4 视角；主体占场景高度约 70%，细节镜头保持连接点可见。
- 色板：纸白 #f5f6f3、浅灰 #dce2df、墨色 #202e2a、次级文字 #68766f、青绿 #167a62、铜色 #b18b56；深色及蓝图主题同时改变场景和界面。
- 灯光：左前上方柔和主光、半球填充，低对比接触阴影。
- 材质：机箱哑光，接口拉丝金属，PCB 深绿，金手指低饱和铜色；细节服务于识别，不增加装饰运动。
- 布局：三维场景为主，右侧步骤说明；手机上场景在上、说明在下，无文字遮盖主要安装点。
- 交互：部件沿安装轴移动、接近插合时减速、镜头平滑切换。页面初始静止，减少动态效果时直接显示目标状态。

## 验收

五章跳步与回退一致；三种厚度和五个盘位正确；练习检查缺垫片、错误插槽、缺紧固件及过早封盖。数字锚点误差 <1 mm；运动采样检查非预期穿透。浏览器验证离线零网络依赖、三主题、键盘、390px、减少动态效果、离屏暂停。记录检查范围，不将数字模型等同于实物试装。正式资料生成后更新根完整性清单。
