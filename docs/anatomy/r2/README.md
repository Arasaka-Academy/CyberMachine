# CyberMachine R2 交互结构图

CyberMachine NAS 设备的 R2 结构示意，主板平台为 Radxa Taco V1.61。打开 [index.html](index.html)（深色）或 [index-light.html](index-light.html)（浅色）。两个页面均可离线打开，页面右上角也可切换明暗主题。

- 切换「混合安装 / 全 9.5 mm / 全 7 mm」，查看五盘与可拆垫片的关系。
- 拖动展开滑块，前后风扇模块向外移开，顶盖与顶扇一起升起。
- 点选组件按钮或图中的零件，查看硬盘、固定螺丝、导轨、垫片、主板和三只风扇。
- 选择 01–05 盘位，单独高亮该盘相关零件。混合模式的 02、04 为 7 mm，其余为 9.5 mm。
- 「固定螺丝」和「7 mm 垫片」视图会淡显选中硬盘及对应导轨，露出被遮挡的前后固定点和正 X 侧垫片。
- 结构图取得键盘焦点后：左右键调节展开，Home 装配，End 展开，空格切换装配/展开，数字 1–5 选盘，Esc 暂停巡览。
- 初始巡览只切换组件高亮；点击「暂停巡览」可停留。系统启用减少动态效果时，页面默认静止，用户操作直接切换位置。滚出视口或切换浏览器标签后暂停动画。

## 固定方式

每盘四颗 M3×6 侧固定螺丝，前后各两颗，配 0.5 mm 垫圈。五盘共 20 颗。导轨固定区厚 3 mm，孔为 3.4×6.4 mm 长圆孔；名义旋入硬盘 2.25 mm。以实际硬盘允许的螺纹深度为准。

9.5 mm 硬盘直接安装。7 mm 硬盘在正 X 侧加前后两条 2.5 mm 垫片，保持同一底面与 SATA 定位基准。

维护单盘时，先拆前后风扇模块，卸该盘四颗侧螺丝与独立托脚，再打开底部检修盖，将硬盘向下取出。图中只展示螺丝头和垫圈，埋入部分省略。

## 图与 CAD 的关系

本图用于解释 R2 外壳结构与每盘四点螺丝固定方式。当前仓库仅包含 R2 交互图，未包含对应的 R2 打印项目、试装件或机箱 STEP。

可打印的 [R1 制造资料](../../../hardware/enclosure/r1/) 与其 [装配说明](../../assembly/r1.md) 单独存放；R1 托脚方案与本图的 R2 四点固定方案有区别，不能直接按本图打印或装配 R1 零件。

图中采用的 R2 设计基准如下：

| 项目 | 数值（mm） |
| --- | --- |
| 外形 / 脚垫 | 144 × 168 × 210 / 另加 6 |
| 五盘 SATA X 基准 | 29、50.5、72、93.5、115 |
| 盘位间距 | 21.5 |
| 硬盘包络 Y / Z | 41.5–111.35 / 22.25–122.7 |
| 侧螺丝 X / 两个 Z | SATA X + 0.3 / 32.1、108.7 |
| 侧孔距底面 / 纵向孔距 | 3 / 76.6 |
| Taco 主板上表面 Z | 135 |
| 散热器预留包络顶 Z / 顶扇下沿 Z | 170 / 180，净距 10 |
| 前后 / 顶部风扇 | 120×120×25 / 92×92×25 |
| 前后 / 顶扇安装孔距 | 105 / 82.5 |

为看清结构，图中移除左侧板、底部检修盖与上层 I/O 面板，侧框只保留安装支撑。主板轮廓、器件、硬盘、风扇与官方散热马甲在图中均为简化外形；散热马甲图形没有代表用户实际散热器的完整尺寸。导轨、托脚等按相同基准简化绘制。前、后、顶组件的展示位移分别为 75、60、76 mm，代表示意展开，不能用作装配操作行程。

前扇进风、后扇排风；顶扇向下吹 CM5 与 M.2，上舱从侧面排热。图中扇叶静止，不模拟转速、风量、噪声或温度。

## 交付与复现

- 本目录保存两个独立 HTML，以及 `assembled.svg`、`exploded.svg` 和对应的 `-light.svg` 浅色版本。
- [预览目录](../../images/r2/)保存 `assembled.png`、`exploded.png`、`four-point-mount.png` 与 `7mm-shims.png`。
- `src/model.mjs`：尺寸、坐标和绘图几何；`src/live.js`：交互；`src/style.css`：主题与布局；`src/build.mjs`：生成页面。
- [validation/r2](../../../validation/r2/) 保存三个厚度模式的 `audit-*.json` 和原交付的 `history.log`。
- `src/order-cache.json` 保存已检查的遮挡顺序，与几何源码 SHA256 关联。修改几何后自动失效。

需要 Node.js 20.10+，无需安装 npm 依赖。以下命令在仓库根目录运行：

```sh
node docs/anatomy/r2/src/build.mjs
node docs/anatomy/r2/src/build.mjs --light
```

构建器从脚本位置解析输入输出目录，使用绝对脚本路径时可从其他工作目录启动。HTML / SVG 写入本目录，缓存保留在 `src/`。普通构建可复用遮挡顺序缓存；需要重新求解并运行几何审计时，执行：

```sh
node docs/anatomy/r2/src/build.mjs --audit
```

审计 JSON 写入仓库的 `validation/r2/`。`--quick` 用于快速开发预览，`--draft` 跳过排序求解与审计；这些预览不能代替默认精度的几何审计。`--light` 选择浅色输出。

Anatomy 绘图工具由 Ryan 提供，MIT 许可证见 [src/kit/LICENSE](src/kit/LICENSE)。

原图形检查覆盖三个厚度模式各 61 个采样展开位置，检查真实绘制体的遮挡、穿透、支撑连接和绘图覆盖。它验证的是说明图；实物装配、打印公差、螺丝深度、振动及温度表现仍需试装与实测。[历史日志](../../../validation/r2/history.log)保留原交付时的检查记录，其路径对应当时的交付环境；当前文件以仓库根目录的 [SHA256SUMS.txt](../../../SHA256SUMS.txt) 校验。
